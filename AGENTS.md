## Imported Claude Cowork project instructions

## Render notes (for Claude sessions)
- Site: Quarto 1.9.38 (`quarto render`; install in a fresh container with the `quarto-1.9.38-linux-amd64.deb` from the quarto-cli GitHub releases — quarto.org itself is blocked by the egress proxy). Quarto cannot run on the mounted folder inside the device shell (sqlite "disk I/O error", temp dirs cannot be removed) — render in the cloud container instead: stage `_quarto.yml`, `_header.html`, `_footer.html`, `styles.css`, `pic.png` and the `.qmd` files, run `quarto render`, then commit back only the changed `.html`, `search.json` and `sitemap.xml`. Unchanged pages reproduce byte-for-byte. Caveat: `extension*.qmd` set an og:image, and Quarto writes the image's width/height meta tags only if the PNG is present — stage `accweb-map.png`/`accweb-map-zh.png` too, or do not commit `extension*.html` (those tags would be dropped).
- CV: sources live in the sibling repo `../yyliou/cv/*.Rmd` (8 variants) and are built with `Rscript render.R` (rmarkdown → xelatex, template `jenpan-latex-cv.tex`). Needs R + rmarkdown + xeCJK (texlive-lang-chinese) + TeX Gyre Pagella + the 源雲明體月 (GenWanMin2TW) fonts from `fonts/`. R is not installed on the device shell either — render the CVs in the cloud container too: `apt-get install -y r-base-core r-cran-rmarkdown texlive-lang-chinese pandoc`, copy `fonts/GenWanMin2TW-*.otf` into `/usr/local/share/fonts/` and run `fc-cache -f` (family name 源雲明體月), then stage the 8 `.Rmd` + `render.R` + `jenpan-latex-cv.tex` and run `Rscript render.R`. The container build is NOT identical to the Mac build: the Mac runs TeX Live 2026 (xdvipdfmx 20260317) and has no microtype, the container has TL 2023 (xdvipdfmx 20220710) with microtype installed. Rendering an unchanged .Rmd in the container and comparing page images against the Mac PDF shows (a) microtype protrusion shifting Latin line breaks — fixable by neutralising the `\IfFileExists{microtype.sty}` line in a container-only copy of `jenpan-latex-cv.tex`, after which the English CV matches — and (b) xeCJK punctuation spacing that still differs on every page carrying Chinese text, which TL 2023 cannot reproduce (CTAN/TinyTeX downloads are blocked by the egress proxy). Page counts and content do match. Also install only GenWanMin2TW-R and -SB in the container (NOT -M), or fontconfig picks M as the CJK bold and the headings come out lighter than the Mac's SB. So: edit the .Rmd here, but let the user run `Rscript render.R` on the Mac for the PDFs — macOS Terminal/RStudio can only be granted click-only computer-use access, so the render cannot be driven from a session. Paper titles appear in both the site (`research*.qmd`) and all 8 CV files — change all of them together.
- Git on the mounted folder: use `git --no-optional-locks status`; plain `git status` leaves a `.git/index.lock` that cannot be deleted from the device shell (move it to `_to_delete/` if it happens).
